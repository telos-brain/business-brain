# Name the Excuse, Then Work

Some obstacles are real. Many are a story that keeps the hard part
off today's list. Naming the excuse does not make you cruel. It
makes the next hour honest.

## Steps

1. Write the reason the work is not happening.
2. Ask: if this reason were gone at noon, would we start? If yes,
   it is an excuse, or a solvable block.
3. Name it out loud. Then do the smallest piece of the actual work
   (**BUS301**). Solve the block only if it is still in the way
   after that.

## Rules

- A real lion is a plan (avoid, reduce, go around). An excuse is a
  sentence that survives every workaround.
- Do not humiliate. Name the pattern, then work.
- Distinct from **ADV603** (step aside from a real trap). This
  skill is the *fake* trap that keeps the shop closed.
