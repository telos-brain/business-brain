# Assume We Are Wrong

A forcing function to break tunnel vision. Assume the current root cause or
solution is **completely wrong** and set it aside. What is the next most
likely explanation?

Use this as Technique 1 of a proportional review (**DEC101**). Do not combine
it with the later techniques in the same pass.

## Steps

1. State the current solution or root cause clearly — one or two sentences.
2. Explicitly rule it out as a thought exercise. Do not argue for it.
3. Generate the next most plausible explanation that still fits the evidence.
4. Compare the two. Does the new explanation fit the evidence better?

## Rules

- The point is the comparison, not a theatrical reversal. If the original
  still fits better, keep it and say why.
- Do not invent evidence to support the alternative.
- One alternative is enough. Do not brainstorm a list.
