# Proportional Critical Thinking

Apply critical thinking **in proportion to risk and impact**. Do not run every
technique at once. Work through them **one at a time, in order**. Stop when
the risk and impact level is satisfied.

Load each technique with `get_skill` only when this guide says you need it.
Do not inline the technique — follow the loaded skill.

## Proportionality

| Risk / impact | Approach |
|---|---|
| Low risk, simple fix | Apply the fix. No technique needed. |
| Medium risk or uncertain diagnosis | **DEC102** then **DEC201**. |
| High risk, live environment, or stuck investigation | All four, in order: **DEC102**, **DEC201**, **DEC301**, **DEC401**. |
| Review of completed work | **DEC102** and **DEC201** as a minimum. |

## Order

1. **DEC102** — Assume we are wrong
2. **DEC201** — Assume multiple root causes
3. **DEC301** — Challenge assumptions
4. **DEC401** — Map blind spots

After each technique, decide whether the current risk/impact level is
satisfied. If it is, stop. If a technique changes the diagnosis, start the
sequence again from **DEC102** against the new diagnosis — do not skip ahead.

## Output

Write the analysis down so the reasoning is visible to whoever owns the work
(a short comment, note, or reply — not an essay).

If a **new** root cause or blind spot is identified, treat it as a **separate
piece of work** rather than expanding the current one — unless the current
work is still in progress and the new cause is required to finish it.
