# One-way and Two-way Doors

Bezos's Type 1 / Type 2 split. The question is: **if we are wrong, can
we walk back without lasting damage?**

- **One-way (Type 1)** — consequential and hard to reverse. Walk through
  and you cannot return. These need method, consultation, and time.
- **Two-way (Type 2)** — changeable. A bad call can be reopened. These
  should be made quickly by a small group or one person with judgment.

Most decisions are two-way. Organisations get slow by putting a Type 1
process on Type 2 doors. They go extinct by putting a Type 2 process on
Type 1 doors.

## Steps

1. Ask: if this is wrong, what does it cost to undo — money, time,
   trust, legal position, data you cannot unspread?
2. Label the door. If undo cost is similar to or less than the cost of
  waiting, it is two-way.
3. Match the process:
   - Two-way — decide with the information you have (~70% is enough).
     Do not run the heavy review.
   - One-way — slow down. Load **DEC101**, **ADV601**, **ADV602** as
     the stakes justify.
4. If a one-way door can be rewritten as a two-way experiment, prefer
   that rewrite (**DEC601**).

## Rules

- Irreversible is not the same as important. A cheap, permanent public
  commit can be one-way. A large, reversible trial can be two-way.
- Do not use "this feels big" as the test. Use the undo cost.
- After a two-way decision, disagree-and-commit. Relitigating a
  reversible call is a hidden Type 1 process.
