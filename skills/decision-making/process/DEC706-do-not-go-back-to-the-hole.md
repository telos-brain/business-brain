# Do Not Go Back to the Hole

A hole you have climbed out of is still a hole. Returning "just this
once" is how the pattern owns you again. The door you leave open is
the decision.

## Steps

1. Name the pattern that already failed (the habit, the deal, the
   person, the shortcut).
2. Ask: is the next step the same shape, with a new excuse?
3. If yes, close the door — a rule, a smaller bet, or a different
   path. Do not rely on memory of the last fall.

## Rules

- "This time is different" needs a *mechanism*, not a mood
  (**DEC301**).
- Shame about the last time is not a lock. A changed path is.
- Distinct from **DEC801** (extract the lesson). This skill is
  *do not walk the same ground*.
