# When Information Will Not Help

Information has **decision value** only if some plausible result would
change what you do. If every likely answer leads to the same action,
the information may be interesting — it is not worth the delay.

Uncertainty alone does not justify waiting. The cost of delay (missed
window, frozen team, a two-way door left shut) is part of the price.

## Steps

1. State the action you would take *now*.
2. Name the next fact, study, or conversation someone wants.
3. Ask: what result would flip the action? Write the flip. If you
   cannot name one, the value of that information is zero for this
   decision.
4. If a flip exists, ask whether you can actually get that result in
   time, and whether it is cheaper than deciding now. If not, decide.

## Rules

- "We would feel more confident" is not a flip.
- A two-way door (**DEC701**) rarely needs 90% of the data you wish
  you had. Waiting for it is usually too slow.
- Distinct from **ADV202** (find the questions that *would* flip).
  This skill is the stop rule when they would not, or cannot be
  answered in time.
