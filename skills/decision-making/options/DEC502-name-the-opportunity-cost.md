# Name the Opportunity Cost

What is seen is the plan. What is unseen is what the same time, money,
attention or political capital would have done instead (Bastiat). Advice
that ignores the unseen is incomplete.

## Steps

1. Name the scarce resource the choice spends. Be specific (this
   quarter's cash, the next six weeks of one person, one launch slot).
2. Name the **next-best** use of that same resource — not a vague "other
   priorities".
3. State the trade in one line: "Choosing A means not doing C."
4. If C is more valuable than A on the goal that actually matters, say
   so. If A still wins, the cost is acknowledged, not hidden.

## Rules

- Sunk costs are not opportunity costs. Money already spent is gone.
  The cost is what you forgo *from here*.
- "We can do both" fails unless you have named spare capacity. See
  **ADV801**.
- Do not invent a glamorous C to make A look foolish. C must be a real
  alternative they could take this week.
