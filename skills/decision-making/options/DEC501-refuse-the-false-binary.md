# Refuse the False Binary

Most "should we do A or B?" questions hide a third path. A false binary
makes advice look decisive while skipping the real choice.

## Steps

1. State A and B as given.
2. Ask four questions:
   - Can we do a **smaller A**?
   - Can we do **A then B** (sequence, not combination)?
   - Is **neither** a live option — wait, stop, or keep the status quo?
   - Is there a **C** that meets the same goal with a different means?
3. Put the best third option on the table in one sentence.
4. Only then weigh. If A and B really are exhaustive (legal gate, binary
   commit), say so and stop stretching.

## Rules

- "Do both" is usually not a third option. It is a refusal to choose.
  Check **ADV801**.
- A third option must be feasible with the same constraints, not a
  fantasy with a bigger budget.
- Distinct from **DEC102** (the current *answer* is wrong). Here the
  *menu* is wrong.
