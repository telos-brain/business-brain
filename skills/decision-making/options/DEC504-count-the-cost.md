# Count the Cost

Beginnings are cheap to announce. Finishing has a bill — time, cash,
attention, and the work you will stop (**ADV801**). A plan that cannot
name the bill is a wish with a start date.

## Steps

1. Name the finished state in one line (what "done" looks like).
2. List what it will take to get there: money, calendar, people,
   and the work that must pause.
3. Ask: can we pay that bill if the middle is worse than the
   brochure? If not, do not start — or start a smaller tower
   (**DEC701**).

## Rules

- Optimism about the middle is not a cost count.
- "We will figure it out" is a decision to start without a bill.
- Distinct from **DEC502** (what you forgo by choosing). This skill
  is what the *chosen path itself* will consume.
