# Challenge Assumptions

Identify every assumption made — about the problem, the people involved, the
environment, the data, or expected behaviour — and ask what happens if one
is wrong.

Use this as Technique 3 of a proportional review (**DEC101**). Run it after
**DEC102** and **DEC201**, not at the same time.

## Steps

1. List all assumptions explicitly — stated and implied.
2. For each, ask: how confident are we? What evidence supports it?
3. Identify the assumption **most likely to be wrong**.
4. Re-frame the problem with that assumption removed. Does the diagnosis
   change?

## Rules

- Implied assumptions matter more than the ones already written down.
  Typical hidden ones: "the report is accurate", "the user did the obvious
  thing", "the environment matches what we think it is", "this worked
  yesterday so nothing upstream changed".
- Challenge **one** assumption in the re-frame — the weakest. Do not remove
  all of them at once.
- If the diagnosis does not change, keep the original and record the
  assumption as tested.
