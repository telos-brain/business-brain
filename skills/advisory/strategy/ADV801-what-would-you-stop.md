# What Would You Stop

Strategy is choice. Agents and busy people default to adding. Every new
commitment spends a scarce resource that is already allocated — even if
nobody named the allocation.

## Steps

1. Name the scarce resource this plan spends (time, cash, attention,
   reputation, a key person's calendar).
2. Ask: what is that resource doing *today*?
3. Name the thing that gets less — a project, a customer, a standard,
   a rest. "We will work harder" is not an answer.
4. If nothing can be stopped, the honest advice is "not now" or "this
   replaces X". Do not bless an addition with no subtraction.

## Rules

- Stopping includes deferring, narrowing, or killing a half-finished
  piece of work. Be specific.
- A stop that nobody will feel is not a stop.
- Distinct from **DEC502** (the next-best *use* of the same resource).
  This skill demands an explicit abandonment in the current load.
