# Questions That Change This

Useful inquiry is scarce. List questions that would **change what you
advise**. Drop every question that is merely interesting.

## Steps

1. State the recommendation you would give *with what you have now*
   (even if it is tentative).
2. For each uncertainty, ask: if I learned the opposite of what I assume,
   would I advise something different?
3. Keep only the questions that pass that test. Cap at **four**. Prefer
   two or three.
4. If memory might already hold the answer, call `ask_question` instead of
   posing it to the caller.

## Rules

- A good question names a fact, constraint, or preference — not "tell me
  more".
- "What would have to be true for this plan to be right?" is one question,
  not an invitation to a workshop.
- If no remaining question would flip the advice, stop asking. See
  **DEC702**.
