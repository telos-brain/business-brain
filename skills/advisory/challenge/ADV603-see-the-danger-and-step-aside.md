# See the Danger and Step Aside

Foresight that does not change the path is decoration. A visible trap
is a gift. Walking in anyway to prove nerve, loyalty, or momentum is
how people spend options they already had.

## Steps

1. Name the danger in one line — the trap, the person, the door.
2. Ask: is this still optional? If yes, step aside or shrink it
   (**DEC701**, **DEC601**).
3. If you must go on, change the path so the trap is no longer the
   road. Do not call that courage.

## Rules

- Seeing it and continuing unchanged is not bravery. It is waste.
- "We have come this far" is how a seen trap gets walked into.
- Distinct from **ADV602** (the one constraint that kills the plan).
  This skill is *you already see it — move*.
